DataBeam v0.7.1 adds Linux ARM64 packages and simplifies release downloads.

- Add Linux ARM64 `.deb` and AppImage packages, automatic updater support, and architecture-specific website links.
- Publish version-free filenames only; stop generating versioned compatibility copies.
- Remove the Update button notification dot while retaining the yellow update hint.
- Show the latest news first in Troubleshoot, followed by the guide and Previous releases.

**Updating:** v0.7.0 users can update through the app. Users on v0.6.7/v0.6.8 must download and install a current version manually once because those older updaters require versioned filenames. In-app updates preserve the installed filename.

**Linux has not been tested on a Linux device.** ARM64 packages are built on a native ARM64 runner; GUI, transfers, and automatic installation still need on-device testing. macOS changes have not been tested on a Mac device.
