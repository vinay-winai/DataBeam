## Croc transfer fixes

- **Bundled patched Croc engine:** DataBeam includes `11.2.5-databeam-keepalive-route`, built from verified upstream source. The receiver now skips relay keepalives during its local-probe handshake, fixing the reproduced `flate: corrupt input before offset 6` failure. The engine is included in the app and can be restored from its bundled copy.
- **DNS handling:** Public relay names are resolved through the operating system before launching Croc. A DNS failure can retry once using the same code and relay before payload transfer starts. Actual DNS failures show the DNS/VPN guidance, with the original error retained in the log.
- **Accurate transfer routes:** LAN discovery and direct transfers remain enabled. Direct transfers are now reported correctly instead of being mislabeled “via public relay” because of Croc 11.2.5's older output format.
- **Random transfer codes:** Random mode uses Croc-style three-word codes. Copy Code and QR controls appear correctly, and successful random-code transfers no longer show “Croc send ended before starting.”
- **Received text:** App-generated route log entries are no longer mistaken for the received message.
- **Croc process handling:** GUI launches ignore inherited stdin, report the final transfer error, and avoid replaying transfers after payload has started or a compression failure has occurred.

## Platform and update fixes

- **Croc updates:** Automatic engine upgrades remain held while the patched engine is required. The Check Croc Update button is hidden while pinned. macOS and Linux also disable automatic Croc update checks and hide the Windows-only settings controls.
- **System tray:** Tray support is Windows-only. macOS and Linux quit normally when the window closes; saved tray settings cannot enable tray behavior there. Windows tray event handling and restore behavior were improved.
- **Release UI:** The tray debug-log option is hidden in release builds, and saved debug settings cannot enable release logging.
- **Release packaging:** Fixed macOS/Linux packaging metadata and pinned the packaging tool version. Windows downloads include both the executable and a ZIP with licenses; macOS and Linux packages include the patched engine.

LAN transfers can still fall back to a public relay when the peers cannot establish a local connection. A VPN changed the DNS outcome in testing on this PC; it did not establish that every DNS timeout has the same cause.
