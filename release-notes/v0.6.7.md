Preview release of DataBeam v0.6.7 with application self-updates and troubleshooting news notifications.

## Application updates

- Add an Update button that checks for new stable DataBeam releases at startup and every three hours. Click it to check manually when no update is available.
- Show an orange notification badge when a newer stable version is available. Clicking Update downloads the platform package, verifies its size and SHA-256 against the release manifest and GitHub asset digest, installs it, and restarts DataBeam.
- Keep transfers protected: installation waits until transfers, scheduled retries, and Croc engine updates are stopped. New transfers and engine updates cannot start during application update preparation.
- Portable Windows EXEs and Linux AppImages update in place. Installed macOS app bundles update from the appropriate DMG after bundle identity, version, architecture, and code-signature checks. Portable installs and macOS apps need a writable application folder.
- Linux DEB installations use the system administrator authorization dialog through PolicyKit and dpkg.
- Preserve the previous portable app or macOS bundle if replacement or restart fails. Remove staging files after the restarted app confirms startup and the helper exits. DEB updates use the system package manager and do not implement automatic package downgrades.

## Troubleshooting guide and downloads

- Add an unread badge to the Troubleshoot button when the online Markdown guide changes. Check at startup and every 30 minutes, clear the badge when opened, and remember read status across restarts.
- Correct the app's troubleshooting URL. A compatibility page keeps the old misspelled URL working in existing app versions.
- Windows download links on the DataBeam website now select the portable EXE directly.

## Validation and preview scope

All 104 application tests pass. Native Windows executable tests verify replacement after the running process exits, restart confirmation, rollback after deliberately failed startup, staging cleanup, and preservation of the installed app. A live GitHub release download also passed checksum verification without installation.

The macOS updater modules passed an Apple Silicon type check. Actual macOS/Linux installation and a full Update-button upgrade between two real DataBeam builds still need device testing. This preview is intended to test those flows.

Install this preview manually to get the updater. Its automatic checks follow stable releases and do not offer other previews or downgrade to v0.6.6. The stable Latest release remains v0.6.6.
