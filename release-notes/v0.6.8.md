DataBeam v0.6.8 fixes notification badge rendering and makes available updates easier to notice.

- Draw the Troubleshoot and Update notification dots directly, avoiding missing-character squares from font rendering on Mac.
- Show the update-available hint and Update button highlight in yellow.
- Add a short Linux Wayland drag-and-drop suggestion under Common UI Issues in the troubleshooting guide: try `env -u WAYLAND_DISPLAY databeam` in the meantime, or use the file / folder buttons.

**Linux has not been tested on a Linux device.** The Linux UI, automatic update flow, and suggested Wayland workaround remain unverified on-device.

The bundled engines remain unchanged: this release includes Croc 11.5.5-databeam and the existing Sendme fixes. Croc 11.6.0 was evaluated separately and is not included.

Windows application tests passed locally. The release action builds the Windows, macOS, and Linux packages. DataBeam v0.6.7 users can install v0.6.8 with the app's Update button after it detects the new stable release.
